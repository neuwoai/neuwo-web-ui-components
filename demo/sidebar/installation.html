Installation

Link the components stylesheet and load the library script, as for every other element. The sidebar's recipe is part of neuwo-components.css, and its entries take the .neuwo-nav-link look that ships in the same file. 

<link rel="stylesheet" href="/dist/neuwo-components.css" />
<script type="module" src="/dist/neuwo.js"></script>

Then put the sidebar first in a flex row beside the page's content. Each entry is a <neuwo-nav-item> with the page in href, written as a path from the site's root or as a full URL, and a section that folds is a <neuwo-nav-section> holding its entries, its own page first. 

<div class="shell">
  <neuwo-sidebar label="Documentation" current="/guides/installation/">
    <a slot="brand" href="/"><neuwo-logo variant="bg-dark"></neuwo-logo></a>
    <neuwo-nav-item href="/">Getting Started</neuwo-nav-item>
    <neuwo-nav-section label="Guides">
      <neuwo-nav-item href="/guides/">Introduction</neuwo-nav-item>
      <neuwo-nav-item href="/guides/installation/">Installation</neuwo-nav-item>
    </neuwo-nav-section>
    <a slot="footer" href="https://neuwo.ai/">Back to neuwo.ai</a>
  </neuwo-sidebar>
  <main class="content">...</main>
</div>
